## 自动精选与正片文本筛查

流程为 S1 转写 → S2 规则粗筛 → S3 可用性判定 → S4 精选编排 → S5 正片文本筛查 → S6 渲染。直接剪辑和虚拟时间线剪辑共用流程；已有成片重组继续使用自己的流程。无需人工审核，也不强制填写商品名称。

S4 给完整 S3 候选池标注主题、具体事实、对象、可入选性、相邻依赖及理由。纯夸赞、故事、场控、无对象保证和事实冲突等应标记不可入选。同一事实的不同说法使用相同事实键，新增事实保持区分。模型输出具体候选 ID、角色和主题块；代码验证覆盖率、ID、事实重复、可入选性、依赖、开头主题及主题连续性，拒绝面料→颜色→面料的回跳。AI 负责语义标注和选择，代码负责执行约束，不能用结构验证保证语义判断百分之百正确。

S5 按成片播放顺序一次查看完整文本及对应原始时间范围，检查承接、指代、残句、重复、空泛信息和对象冲突，返回问题 ID、原因及动作，不改写原视频话术。

依赖可以指向前句或后句。代码递归计算完整依赖组，排除含不可用句、循环、跨主题或重复事实的组合；入选后自动补齐并按原素材时间顺序连续播放，共享上下文只保留一次。补齐后仍校验主题、事实和时长。无法通过校验时最多进行一次带错误反馈的重新编排，不无限循环，也不放松校验直接出片。

- 删除后语义完整、时长在设定范围内：代码直接删除，保留其他句子，不调用编排补句。
- 删除后低于下限：S4 从原 S3 候选池补新增信息，排除已淘汰句。即使 AI 判断通过，代码发现低于下限且仍有新增事实候选，也会要求补句。
- 替换、承接修复：带问题、原方案及全池候选回到 S4，再进行 S5 全文检查。
- 每个方案最多三次 S5 尝试，首次、超时、非法返回均计数；最多两次修订。第三次后不再修订，当前有效方案自动以 `limit_released` 进入 S6，不冒充质量通过。优质候选不足可出完整短片，不填充重复话术。时间上限沿用完整长句溢出容忍规则。

`semantic-selection.json` 保存全池标注，`order.json` 保存当前编排，`review.json` 保存审查次数、问题、修订动作及放行类型；均作为节点产物登记。审查预算在调用前落盘，恢复不重新计数。文本、时间范围或编排变化使旧放行失效。历史完成任务和视频保留；数据库原位增加 S5。历史计划要重新执行 S4 后，才使用新流程，不会自动改动已有成片。

回归测试使用结构化 AI 替身验证删除、补选、三次上限、恢复、约束和迁移，并用真实 ffmpeg 验证出片。没有重新调用 MAX 挚爱的 S3 模型，也没有将替身测试宣称为真实素材质量验收。
