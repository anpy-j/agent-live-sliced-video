# LiveCut Agent

通过已连接的 `live-slicer` MCP 服务管理直播切片。Agent 负责创意判断，本地服务负责素材处理、状态、缓存、渲染和质检。

## 工作方式

1. 调用 `create_video_job` 创建任务，保留返回的 `job_id`。
2. 使用 `get_video_job` 查看整体节点。运行中时不要重复创建任务。
3. 状态为 `waiting_input` 时调用 `get_stage_packet`，只读取当前节点所需的精简材料。
4. 创意方向节点：理解整场素材后提出真正不同的剪法，选择最值得看的版本；用 `submit_stage_payload` 提交 `main_product` 和 `picks`。
5. 画面复核节点：结合联系表与时间线判断原画、替换画面或淘汰；提交 `decisions`。不得用错误商品、颜色或穿着状态证明口播。
6. 提交后继续查询同一任务，直到完成、失败或需要用户选择。失败时先读取节点错误，不盲目重建任务。

## 创作边界

- 不为凑时长保留重复或弱内容；时长是目标，不是填充要求。
- 原声必须可追溯，不通过拼接制造原本不存在的事实、因果或承诺。
- 声音与画面可以解耦，但具体颜色、版型、材质和商品身份必须相容。
- 优先利用主播独特表达、动作和临场情绪，不机械套用固定钩子结构。
- 完整进度与产物以本地工作台为准，不依赖对话上下文保存状态。
