# LiveCut 女装切片 Agent

一个本地优先、模型可配置的女装直播切片 Agent。转写、文本筛查、切点对齐、音画双轨混剪和渲染由项目内置执行内核完成，并通过 MCP 供 WorkBuddy、Codex、Antigravity、OpenCode 等客户端触发。

## 核心能力

- 本地任务队列与独立工作区
- 五个真实生产节点的流程总览、执行事件、错误和结果
- 图片、JSON、日志和 MP4 产物预览
- LiveCut 可主动调用 WorkBuddy、Antigravity、Codex 或 OpenCode CLI 完成一次创意编排，也可回退为人工或外部 MCP Agent 决策
- 新建任务可分别选择文本编排模型和多模态混剪模型
- Multica 可作为第五个 AI 提供方，通过工作区中的 Agent 发起编排 Run
- 在线编辑并自动备份薄 Skill
- 带 Bearer Token 的 Streamable HTTP MCP 入口
- 项目内置女装切片执行内核，不依赖外部旧引擎目录
- SQLite 持久化，服务重启后恢复排队任务

## 启动

首次使用时建议建立独立 Python 3.13 环境安装项目与引擎依赖。

在 Apple Silicon Mac 上：

```bash
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python -e '.[apple-silicon]'
```

在 Windows PowerShell 上：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

启动 Web 控制台（Web 管理端本身没有第三方依赖，Python 3.11 及以上也可直接启动）：

```bash
python -m agent_video
```

打开 <http://127.0.0.1:8787>。MCP 地址为 `http://127.0.0.1:8787/mcp`，客户端配置与密钥可在「MCP 接入」页面复制。

执行内核位于 `agent_video/engine`，随项目代码一起升级；系统设置只需确认引擎 Python 环境。

原生视频文件选择器同时支持 macOS 和 Windows。Windows 使用系统自带的 PowerShell 打开文件对话框，并支持中文文件名和目录；Linux 客户端仍需填写素材的绝对路径。

如需使用 Multica，先安装 CLI 并执行 `multica setup`。随后在「系统设置」填写 Multica CLI 路径；Profile 和 Workspace ID 可留空以使用 Multica 当前默认值。模型选择器会列出工作区 Agent，并显示各 Agent 绑定的底层模型。

首次运行前，在「系统设置」确认引擎 Python。macOS 的虚拟环境解释器通常是 `.venv/bin/python`，Windows 通常是 `.venv\Scripts\python.exe`。

## 当前工作流

1. 页面或 MCP 创建任务。
2. 「素材索引」优先复用可选 SRT/VTT/ASS/SSA/时间码 TXT，并把字幕块起止作为可信边界，不伪造块内逐字时间；有效字幕路径不启动 Whisper，也不预先抽取整条 WAV。只有入选字幕无法可靠对齐、确实需要静音/ASR 兜底时才延迟提取音频。无字幕时只执行一次 ASR，后续复用指纹缓存。
3. 本地脚本先完成违禁过滤、整句、依赖感知近义去重、分类与评分。每条候选都有 `utterance_id` / `atom_id` / `requires_previous` / `requires_next` / `safe_standalone`，依赖关系按未过滤的原始相邻句建立；统一依赖图会递归求闭包并拒绝缺失节点或环。AI 以每批约 35 条审核全部候选；依赖句可保留，但白名单、自动补齐、本地兜底和最终门禁都复用同一闭包规则并按原顺序紧邻选取。
4. 语义审核会分别给出开头适配度、信息增益和销售价值：具体结果、痛点、反差、观点、情绪或故事悬念优先，寒暄、报款、空泛夸赞、喊麦感和单纯长句不算吸引力。编排会比较模型方向、自然时序、利益点递进和替代强开头，再以独立全局门禁检查前 3–5 秒、上下文承接、主商品、商品/颜色跳变、错误因果、重复和信息密度。模型失败时按原素材时序自动降级，不等待人工。
5. 「文本校验与原声锁定」优先把口播安全拆到 1.2–10 秒；没有可靠词级/标点边界时，可保留最长 18 秒的完整声音单元，超过 18 秒仍拒绝。画面独立切成最长约 3 秒的镜头。高清渲染前先用源词时间戳检查切点，再生成低码率 `audio_preview.m4a` 并对这个实际文件执行第二次 ASR，按成片时钟检查漏字、多字、断尾、异常停顿和连接点重叠。
6. 「多模态画面混剪」先局部检查最终入选片段；只对技术坏画面寻找同商品、同颜色且嘴型安全的异时替换，无法确认时保留原始同步画面。
7. 任务的“完成”与 `publish_ready` 分离：模型、切点或质量门禁异常时仍会自动生成可播放降级结果并完成任务；只有全局文案、音频连接点和最终技术 QC 全部通过才会设置 `publish_ready=true`。

## 同一素材多次剪辑

新任务按“原素材 → 多次剪辑”两层归档。同一个未变化的源文件始终进入同一个素材目录，每次创建任务都会建立新的剪辑子目录，因此相同标题也不会覆盖上一版：

```text
workspaces/sources/<素材名>-<素材指纹>/
  source.json
  shared/
    indexes/<字幕或ASR指纹>/
    edit_history.json
  edits/
    <任务ID>-<成片名称>/
      engine/
      visual-mix/
      final-render/
      deliverables/
    <另一次任务ID>-<另一个成片名称>/
      ...
```

转写、字幕块和候选基础索引在素材目录内按字幕/ASR 指纹复用；每次剪辑的 AI 编排、Token、时间线、视觉替换、渲染缓存和最终成片完全隔离。素材级 `edit_history.json` 只记录历次策略、用过的原句和时间范围；新任务把历史使用次数作为极短提示传给编排模型，优先新钩子和新内容，但不会硬删不可替代的强句。源文件或字幕变化时自动使用新的素材目录。

时长是软目标：页面可选择 70–120、120–180、180–240 秒或 30–600 秒自定义范围；自动模式在素材充分时默认 70–120 秒。系统不为凑时长保留废话、近义重复、违禁内容或多余面料讲解。面料按商品分别控制为最多一次；多商品按商品集中，商品内再按颜色集中。
多模态模型只用于受控的替换画面选择，不负责严格逐句动作匹配，也不会自动改写文案或原声。

审片反馈保存问题类型、任务、时间点/片段、商品、期望修改、作用域与规则类型。文本意见只进入文本编排，视觉意见只进入候选画面提示，渲染意见只控制渲染配置；三域均有长度预算。规则支持去重、冲突检测、启停、版本历史和回滚，单次问题只影响当前任务。硬规则未经确定性校验/回归测试不能全局启用。

## 安全

- 默认只监听 `127.0.0.1`。
- MCP 需要 Bearer Token。
- 素材使用绝对路径读取，不自动复制或上传。
- 不向 MCP 暴露任意 Shell 执行接口。
- 文本编排进程只接收候选摘要并返回结构化 JSON；多模态阶段只接收本地生成的有界参考图和候选联系表。
- AI 选段必须逐条来自候选摘要；伪造时间、改写原声或重复画面会在渲染前被拒绝。
